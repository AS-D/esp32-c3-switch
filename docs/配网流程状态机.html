点灯 App 远程控制：
App 点「开」→ GPIO10 高电平 → 继电器/MOS 吸合 → 5V 输出通电
App 点「关」→ GPIO10 低电平 → 断开 → 5V 输出断电
断电重启自动恢复上次开关状态（NVS 记忆）
运行中维护
WiFi 掉线 → 自动重连（已存配置）；
持续掉线 > 2 分钟 → 重新开热点配网
配网超时：热点开启 5 分钟无人配网 → 自动重启重新开热点
重新配网：长按板载 BOOT 键 5 秒 → 擦除配置 → 重启进入配网
核心逻辑：只在“没配过网 / 连不上”时开热点，配过网直接读取配置重连
