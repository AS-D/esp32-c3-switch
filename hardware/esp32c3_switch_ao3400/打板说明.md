| 项目 | 参数 |
|---|---|
| 板名 | esp32c3_switch_ao3400 |
| 尺寸 | 36 × 28 mm |
| 层数 | 2 层（双面） |
| 板材 | FR-4 |
| 板厚 | 1.6 mm |
| 铜厚 | 1 oz |
| 表面处理 | 有铅喷锡（HASL）即可，沉金可选 |

| 钻孔 | 含金属化孔（镀铜通孔）与 4 个非金属化 M3 安装孔 |

## 3. 下单参数（在嘉立创下单页选择）

1. 上传 gerber.zip → 系统自动识别 2 层 / 尺寸 36×28。
2. 板材 FR-4，板厚 1.6mm，铜厚 1oz，数量按需（5 片约 ¥20 内）。
3. 表面处理：有铅喷锡（经济）即可；焊盘为喷锡后手工焊接友好。
4. 阻焊颜色：绿色（默认）。
5. 确认 gerber 预览中丝印、钻孔、板框齐全后提交。

## 4. 设计验证结果（已自动化检查）

- 网络连通性（0.1mm 栅格并查集 DRC）：VIN / GND / OUT- / IO10 / GATE 5 个网络各 1 根连通，无开路、无短路 → **PASS**。
- 同层最小间距扫描：不同网络最小间距 0.2mm（0603 焊盘间隙），无 <0.15mm 风险对 → **PASS**。
- Gerber 回读：8 个文件均可被 gerbonara 正常解析，板框 36×28 闭合，钻孔文件格式标准。

## 5. 接线与使用（对应 README 方案 B）

```
USB 5V ──┬── J1(+) VIN ──┐            ┌── J3(+) VOUT+ ── 负载 5V
         │               │ 板载滤波   │
         └── ProMini 5V (J2) │          └── 负载 5V 也可直接从 J2 引
负载 GND ── J3(-) OUT- ── Q1.D (漏)
Q1.S(源) ── ProMini GND (J2)
Q1.G(栅) ── 100R (R1) ── ProMini IO10 (J2)
Q1 G-S 间 100k (R2) 下拉 → 默认关断
```

- J1：输入 5V（标 + / -）；J3：输出（+ 接负载 5V，- 接负载 GND）；J2：1×3 排针插 ProMini（5V / GND / IO10 三脚，注意方向按丝印）。
- 点灯 App 置高 → IO10 高电平 → AO3400 导通 → OUT- 接通地 → 负载通电。
- 注意：本方案为**低边开关**，负载 GND 必须经过本板 OUT-，负载 5V 取自 J3(+) 或 J2 5V。

## 6. 焊接提示

- **C1（220µF 电解）**：丝印横杠端为负极，对应 PCB 上带横杠标记的焊盘（右上角）；接反会发热/鼓包。
- **Q1（AO3400 SOT-23）**：丝印上小点为 1 脚（G 栅极，左下角）；焊接温度 ≤350℃、时间 <5s。
- 插件顺序建议：先焊 SMD（C2、R1、R2、Q1），再插件（J1、J3、J2、C1）。
- 4 个 M3 孔为安装孔（非镀铜），用尼龙柱/铜柱加螺丝固定。
